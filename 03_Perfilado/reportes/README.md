# Reportes De Perfilado

Salidas tabulares generadas por el proceso exploratorio de calidad.

| Archivo | Medicion |
|---|---|
| `reporte_archivos.csv` | Inventario y dimensiones por archivo |
| `reporte_columnas.csv` | Estructura y completitud por variable |
| `reporte_duplicados.csv` | Duplicados exactos e identificadores repetidos |
| `reporte_formatos_invalidos.csv` | Valores que no cumplen formatos analizados |
| `reporte_inconsistencias.csv` | Inconsistencias categorizadas |
| `reporte_outliers.csv` | Observaciones atipicas detectadas |
| `reporte_candidatos_duplicados_paciente.csv` | Candidatos preliminares de identidad |
| `resumen_calidad_por_archivo.csv` | Consolidado de hallazgos por archivo |
